# Contributing

Thanks for considering a contribution to `kodpreneur-dooel/sent-dm`.

## Development setup

```bash
composer install
composer test
composer analyse
composer format
```

## Pull requests

- Keep changes focused and small.
- Add or update tests for behavior changes.
- Run `composer test`, `composer analyse`, and `composer format` before opening a pull request.
- Document user-facing behavior in `README.md`.

## Coding style

This package follows Laravel conventions and uses Laravel Pint for formatting, Pest for tests, and PHPStan/Larastan for static analysis.

## Security

Do not report security vulnerabilities through public issues. Please contact KODPRENEUR DOOEL privately at `contact@codepreneur.mk`.
